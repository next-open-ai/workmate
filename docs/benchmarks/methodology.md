# Benchmark 方法规范

> 状态：已采用的评测治理框架  
> 更新日期：2026-09-23

每项 Benchmark 必须记录：Benchmark ID 与版本、Git 提交和制品、软硬件与网络、Provider/模型/Prompt/Tool/Verifier 版本、数据集版本和许可、并发与超时、预热和正式轮次、随机种子、原始结果位置与哈希、统计汇总以及异常说明。

## 可比性规则

- 对照实验使用相同数据集、环境等级和参数；
- 至少报告样本数、中位数和尾部指标，不只报告平均值；
- 外部 API 单独报告网络与供应商波动；
- 质量评测说明判分器、人工复核方式和失败分布；
- 口径变化必须升级 Benchmark 版本，不覆盖历史基线；
- 未达到最低样本量或环境漂移超限时，结果标记为无效，不进入基线。

Benchmark 默认不阻断发布；只有被发布标准明确引用的指标才成为质量门禁，其评测定义仍保留在本目录，发布结论进入 `docs/quality/releases/`。
