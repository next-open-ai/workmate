# 对话附件能力发布说明

## 用户可见变化

- 对话输入支持 PDF、DOCX、XLSX、XLS、CSV、Markdown、TXT、PNG、JPEG、WebP 和常用音频。
- 统一回形针菜单、拖放上传、解析状态卡片和发送后的文件摘要。
- 已发送文件可显式保存到资产库；表格可显式导入数据工作台。
- 附件默认只用于当前对话，不会自动进入任何长期资料库。
- 设置页可查看临时附件空间、预览清理并执行过期清理。

## 技术变化

- 文件使用二进制流上传，避免 Base64 额外体积和内存开销。
- PDF/DOCX 使用本地 MarkItDown/Docling，表格使用 SheetJS。
- 长文档按问题选择相关片段，模型上下文有严格长度上限。
- 增加真实文件签名、页数、工作表、单元格、数量和容量约束。
- 音频已纳入结构化会话附件，临时 ASR 副本随附件生命周期清理。
- 模型专用的解析上下文不会通过会话 API 返回给客户端。

## 发布验收

- macOS：运行 `pnpm chat-attachments:regression` 和全量质量命令。
- Windows：必须使用正式安装包验证 PDF/DOCX 解析运行时、中文及空格路径、音频转写和首次解析耗时。
- 回滚：附件契约均为可选字段；旧会话和无附件消息保持兼容。若需回滚 UI，可停用附件入口，原有图片消息仍可读取。
