# 对话 Markdown 排版

> 状态：已实现｜规格版本：1.0｜更新日期：2026-09-29

| ID | 需求 | 验收摘要 |
| --- | --- | --- |
| CHAT-MD-01 | 智能体回答中的 Markdown 空行只表达块级分隔，不应额外生成占据整行高度的视觉元素。 | 标题、段落、列表间不会因空行与 CSS 外边距叠加产生大块留白。 |
| CHAT-MD-02 | 正文、标题、列表、引用、代码块和表格应使用统一、紧凑且可读的垂直节奏。 | 长回答可连续阅读，标题仍保留清晰层级，列表和表格不会拥挤。 |
| CHAT-MD-03 | 排版调整不得改变 Markdown 内容、安全转义、链接策略和表格结构。 | 仅调整空行输出和展示样式。 |
