# ASR 工作口令首版（VC-T1）

VC-01：聊天语音输入增加「口令执行」开关（默认关闭）和「任务语音提示」（默认开启），按用户保存 UI 偏好。首版用明确收尾口令（开始干活/开始执行/开始工作/现在执行/执行吧/开始吧/动手吧）而非通用语义模型；需要至少 6 字的工作正文，否定、引用、疑问不自动执行。转写稳定 1200ms 后显示 1 秒取消入口。文本修订、手动取消、停止、关闭开关、切换聊天、离开聊天页、任务忙碌均撤销候选；不猜测历史中的「就按刚才的做」。未命中仍可手动发送。

VC-02：自动提交使用现有 submit 快照和当前对话/附件，提交后停录，不额外启动语音大模型；首版仅当前员工的正常服务端聊天，不支持协作者/自动调度自动提交。复用原权限审批，不扩大工具权限。一次录入只提交一次；失败恢复草稿，不自动重试。

VC-03：sendMessage/addMessage 增加可选本地 onRunAccepted(sessionId,runId) 回调，仅服务端实际返回 runId 后调用；不改 HTTP Schema。带该回调的语音提交在网页/桌面均走正式服务端聊天，不走旧 stateless 路径。任务通知监视指定会话/run，审批续跑仅跟同 turnId，其他回合不混入。轮询真实 running/completed/failed/cancelled/waiting-approval，事件去重；状态获取失败不声称完成。最长监视 24 小时后停止，不取消工作。

VC-04：本地固定 WAV，开始/完成各两句轮换，失败/审批/取消各一句；不读正文、不声称文件存在、不使用运行时 TTS/API。播放队列串行、录音/实时通话时暂停提示队列，关闭提示清队列，播放失败降级文字。退出登录/组件销毁释放监视与播放器；切应用页面保留监视，切聊天仍可通知原任务但不切换当前会话；不保证应用退出后通知。录音停止不取消后台工作；静音只影响提示。

VC-R1：口令正例、否定/引用/疑问/缺正文反例。VC-R2：生产候选调度/取消/修订/快照提交。VC-R3：监视开始/完成/失败/审批续跑、其他回合隔离、重复状态、网络错误与释放。VC-R4：音频资产完整性、队列/静音/播放失败；现有 VUI-R1–R7 不退化。入口 scripts/voice-command-regression.mjs 与 voice-composer-regression.mjs，renderer typecheck/build。真实录音/音质/浏览器自动播放需人工验收。

范围仅 renderer 本地控制与已有 workspace 回调，不改模型/后端/编排状态机。无数据迁移，默认关闭；关闭「口令执行」恢复纯转写，关闭提示恢复无声；回滚可移除可选回调和新组件。音频由构建时本机系统中文合成，静态文件随应用发布，无云端成本。
