# 内嵌语音交互（VUI-T1）

- VUI-01：聊天入口使用输入框内嵌语音条，不遮挡对话；模式可在开启前选择，默认沿用配置，通话中禁止切换。配置测试保留原弹窗兼容。
- VUI-02：ASR 全量转写实时替换本次识别片段，不重复追加，保留已有草稿；录音/最终修订期间输入框只读，但已有非空文字时可以手动发送；结束、失败、关闭均保留已录入文字，默认不自动发送（显式开启 VC-01 口令执行时例外，见 voice-command.md）。可暂停麦克风、继续、结束等待最终修订；新一轮录入接在已有草稿之后。
- VUI-03：实时对话使用同样语音条，提供收音/回复声波、静音、结束和重试。用户与助手字幕显示在语音条中，不写草稿、不重复调用 Agent。字幕为本页临时记录（最多 20 轮），任务消息/附件仍由编排器持久化。切换对话关闭录音且清理临时字幕。
- VUI-04：声波源于实际 PCM/播放采样，不用随机动画伪造录音；静音、断开、关闭时归零。亮暗主题、窄屏重排、按钮键盘操作、状态可读、降低动态效果。连接/麦克风权限错误在语音条内显示，已识别文本保留。

组件边界：VoiceInputDialog / RealtimeVoiceDialog 增加 inline、autoStart 可选参数，默认仍弹窗；共用 VoiceControlBar，波形/草稿/字幕纯函数在 renderer。preview/busy/captions 仅为 Vue 本地展示事件，不更改 HTTP 契约、密钥、员工执行/审批/计费路径。

VUI-05 / VUI-T2（历史设计，已由 VUI-08 取代）：共用 VoiceCaptionStrip，接收本地 VoiceCaption[]；早期版本曾提供字幕轮播和前后切换，当前正式界面不再启用。展开记录不强制滚动，允许阅读旧内容；手动结束通话不保留字幕入口（VUI-07 覆盖早期保留行为）。空字幕不显示；ASR 同样显示本次转写，草稿行为不变。没有新增翻译模型、持久化或服务端变更。

VUI-R5：组件回归覆盖字幕空态、用户/助手分离、最新修订定位、定时轮播、展开暂停、手动切换、全部记录与卸载计时器清理。VUI-T2 可通过移除 VoiceCaptionStrip 恢复原展示，无数据迁移。

VUI-06 / VUI-T3：语音输入期间发送按钮遵循普通草稿的非空/模型配置/任务忙碌条件，不受 ASR busy 限制。用户发送时立即提交当前可见文字快照，关闭本次 ASR，不等待最终修订；发送后的迟到事件不得回填清空的草稿或失败恢复的草稿。失败沿用原发送恢复逻辑，不自动恢复录音。仅改 renderer，不改服务端发送/审批语义；无配置迁移，恢复 ASR busy 发送限制可回滚。

VUI-R6：回归检查真实聊天模板发送条件、submit 的结束录入顺序、预览关闭门禁；挂载真实 ASR 组件，断开录入后注入迟到转写不再产生预览、麦克风释放且关闭服务端会话。保留 VUI-R1 草稿保护和普通发送失败恢复路径。

VUI-07 / VUI-T4：导航到设置/资产等其他页面只是隐藏聊天组件，返回时恢复同一语音条、会话、草稿、字幕，禁止重新创建上游通话；页面外显示「语音进行中」返回入口，提示仍在收音。真正切换聊天会话、退出登录或销毁应用仍释放录音。话筒为开始/停止切换按钮，录音、通话、连接准备期间均可再次点击取消；异步连接迟到不得重新开启。手动关闭/结束/话筒停止实时通话立即清空临时字幕且不显示历史入口；关闭语音输入仍保留草稿。正式智能体消息、任务、成果和审批不受清空影响，挂断不取消已启动的工作。Vue 本地 voiceActive 事件只提示 UI，不改 HTTP/存储；回滚恢复原导航卸载与按钮逻辑，无迁移。

VUI-08：收起状态只显示最新一句字幕，不自动轮播或切换历史；“展开字幕”显示本次通话完整记录。关联工作完成通知属于平台播报，不写入实时模型字幕，也不覆盖最新对话句。

VUI-09：语音条、Vue 根包装层、输入区 Grid 轨道、字幕行和展开记录必须受输入区宽度约束；收起时长文本单行省略，不得撑宽页面或遮挡操作按钮，展开后允许任意语言和连续字符换行。桌面麦克风活动门槛采用可听语音 RMS 下限，低于下限的设备底噪继续作为静音帧发送给服务端 VAD。若上游已经开始转写，但持续静音约 5 秒仍未返回 completed，客户端只兜底提交一次当前回合，再切换官方 mute；没有活动回合时直接 mute，避免底噪让转写永不结束，也避免重复 commit。兼容火山文本转写和音频事件的当前及别名事件名，旧版连续上传回滚配置不变。

VUI-R7：真实语音组件在导航隐藏/恢复期间单次建连且资源保持；最终卸载释放。生产 toggle/open/close 函数回归覆盖两种模式停止、连接中取消、晚到能力/会话结果拒绝、字幕清空与晚到事件拒绝、正式消息不变。静态检查导航隐藏条件、按钮可停止与退出登录卸载边界；人工真机验证另记。

VUI-R1：全量修订不重字、已有草稿不丢、手动修改不被迟到结果覆盖。VUI-R2：实时字幕轮次更新/容量/去重、不进入草稿。VUI-R3：静音/有效 PCM 波形边界。VUI-R4：组件挂载和 mock 事件生命周期、内嵌与弹窗兼容；真实麦克风人工验收单独记录。运行 `node scripts/voice-composer-regression.mjs`、renderer typecheck/build、API 回归（后端行为不变）。无数据迁移；取消 inline 参数可恢复弹窗。
