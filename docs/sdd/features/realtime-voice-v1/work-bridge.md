# 语音工作关联 V1

## 需求 / 任务

- VWB-01：独立 workLinkEnabled 开关，旧配置默认关闭；关闭时不发布或执行工具。任务 VWB-T1：契约和配置。
- VWB-02：发布 discover_capabilities/start_work/get_work_status/cancel_work；服务端绑定用户与组织，按 call_id 去重。任务 VWB-T2：能力桥和火山结果回传。
- VWB-03：工作默认使用通话开始时的当前前台会话与员工，复用历史、Skill、MCP、审批；无当前会话时创建可见会话。挂断不取消任务。任务 VWB-T3：任务事件与前端卡片。
- VWB-04：工具回传只含状态、短反馈、产物数量与工作会话引用；不回传 transcript、reasoning、日志。运行中只更新工作状态；首次完成按 VWB-08 追加一次平台短播报。任务 VWB-T4：输出控制。
- VWB-08：关联工作首次进入 `completed` 时，平台必须主动播放一次不超过 50 字的完成提示。提示从受控模板中按任务稳定选择，由当前实时语音 Provider 使用当前模型与音色播报；不另起浏览器系统朗读、不再次调用工作 Agent。仅当上游通知事件发送失败时，客户端才播放一次内置短提示音。实时通知、普通语音任务监视和兼容回退共享 `taskId + terminal status` 去重键，不得重复播报。任务 VWB-T8：终态事件、Provider 播报与跨通道去重。
- VWB-09：语音关联工作的 `accepted/queued/running/waiting-approval/cancellation_requested` 状态必须同步到主对话输入区；执行期间锁定文字提交并显示紧凑状态，终态自动解锁。失败运行即使已有模型的半句输出，也必须把真实终态错误写入关联对话，不能只在语音层给出推测性的错误摘要。
- VWB-10：语音、手机和远程入口由服务端发起运行时，必须按任务所有者读取 `user:<ownerUserId>:` 作用域下的员工 Skill 清单与关联策略，与桌面文字入口保持一致；仅在作用域数据不存在时兼容读取旧版非作用域键，不得读取其他用户配置。

## 契约和边界

Schema 位于 packages/contracts/src/voice-work.ts。start_work 接收 objective 和可选 employeeId；get/cancel 接收 taskId（即 runId）。任务绑定在 domain KV 中，身份只能由服务端提供。取消仅作用于对应会话当前任务；审批继续通过已有工作台处理，不允许语音模糊批准。原文和产物保留在编排器。

## 验证 / 追踪

VWB-R1 覆盖 01：关闭后拒绝执行；VWB-R2 覆盖 02：重复调用不重复创建任务、跨用户拒绝；VWB-R3 覆盖 03：状态/取消和持久化绑定；VWB-R4 覆盖 04：长输出不进入工具结果。运行 API test、orchestrator test、类型检查、构建。真实火山触发工具与真实员工任务联调单独记录。

VWB-R8 覆盖完成态才生成通知、同一任务文案稳定、50 字长度上限和非终态不通知；Provider 适配回归覆盖通知事件使用当前会话语音输出；VUI 回归覆盖同一 `taskId` 的重复 `local.work_notice` 仅消费一次，Provider 成功时不调用本机朗读，失败时仅回退一次内置音频。

VWB-R9 覆盖失败运行同时保留部分回复和终态错误；前端类型检查覆盖 `VoiceWorkResult` 整体向主工作台透传。人工验证语音启动任务后输入框立即锁定、显示“工作执行中”，完成/失败/取消后自动恢复。

VWB-R10 使用多用户 KV 验证服务端只装配任务所有者关联的 PDF Skill，并覆盖旧版非作用域配置的只读兼容路径。

## 兼容 / 回滚

新增配置默认关闭，无旧配置迁移；新 domain key `voice-work:<runId>` 不修改已有会话结构。关闭关联仅阻止新工具调用，已接受的工作仍在工作台运行。第一版不提供复杂摘要模型，只返回真实状态和产物数量，不将截断原文伪装为摘要。

## 当前对话关联（VWB-05 / VWB-T5）

实时会话创建新增可选 conversationId（UUID），只能绑定同组织同用户的聊天会话；无 ID 的旧客户端保留新建会话兼容路径。聊天入口与配置测试先确保当前服务端会话存在，无当前对话则创建前台对话，失败时明确报错，不静默另建隐藏任务。工作默认员工取会话员工；显式员工仍需校验可用。任务结果触发前台拉取，并在通话期间和挂断后轮询当前会话（切换会话停止）；恢复运行时间、待审批卡片、成果附件。纯语音闲聊仅显示在当前页字幕区（不写入草稿、不再次启动 Agent、不持久化）。

绑定新增可选 turnId，旧绑定按原 run 的 turnId 派生，状态仅跟随同一回合的审批续跑，不得跟随后续无关消息。取消使用预期 runId 原子校验，不能中止新任务。已有活动任务时语音提交返回忙碌，不替换文字任务。VWB-R5：当前会话消息/默认员工/历史复用与身份拒绝；VWB-R6：多回合状态、旧任务取消隔离、审批续跑；VWB-R7：忙碌拒绝与并发幂等。无数据迁移；旧客户端仍新建会话，旧任务保留。回滚客户端 conversationId 即恢复独立会话。
