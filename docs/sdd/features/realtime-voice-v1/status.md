# 手机网页实时通话（2026-10-05）

- MV-T4：增加可选的内置手机 HTTPS 前置服务。独立端口只转发 `/api/chat-mobile/` 的 GET/POST 到回环 API，桌面、设置、管理、编排及其他接口不受影响且不对该端口开放。证书和私钥由运维显式提供，系统不生成或绕过手机信任链；默认关闭。
- MV-T5：桌面版默认开启限定路径 HTTPS 前置；未指定外部证书时自动持久化本地 CA 并签发覆盖局域网 IP 的 TLS 证书。二维码弹窗提供 CA 安装入口；CA 私钥只保存在数据目录，网络变化不轮换 CA。可通过环境变量关闭或换用正式证书。
- MV-T6：修复移动网络瞬断被放大为整通电话结束的问题。SSE 断开仅解除本次订阅，上游会话继续存活并允许浏览器自动重连；客户端设置 15 秒重连窗口，音频上传连续三次失败才结束。临时存储检查失败不再批量关闭所有健康通话。
- MV-T7：修复固定 100ms 分包在移动网络 RTT 超过 100ms 时必然产生积压的问题。上传改为每请求动态排空 100–300ms 音频，积压保护提升至持续 6 秒；CA 二维码改为安装说明页和独立证书下载，明确系统信任步骤。
- MV-T8：手机扫码弹窗改为并列的“快速连接 HTTP / 安全语音 HTTPS / 首次证书安装”三入口。HTTP 是无需证书的默认易用路径，并明确只提供文字、任务同步和文件；语音安全要求不降级。
- MV-T9：手机语音采集增加本地轻量 VAD 节流。人声完整发送并保留约 250ms 前置和 650ms 尾音；环境低声/手动静音期间改为每 4 秒一次静音保活，减少持续无效 HTTP 音频包。
- MV-T10：桌面实时语音增加默认开启的活动门控和设置开关；关闭开关或设置环境变量为 0 时完整保留旧版 20ms 连续传输，便于出现丢字、断句或特殊声学环境时即时回退。
