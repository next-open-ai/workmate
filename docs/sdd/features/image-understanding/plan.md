# VIS-001 实施计划

需求与契约见 [README](README.md)。

1. M1（本轮）：Pi 单员工主模型直接识图；契约 → 会话附件存储/鉴权 → 图文传输和原图追问 → 配置/UI → mock/API/界面验收。
2. M1 真实服务验收（待执行）：选择用户确实拥有的视觉模型配置，使用非敏感测试图片验证描述、文字提取、多图比较和追问；记录实际模型、协议、耗时及失败。不得为了测试擅自替换用户主模型。
3. M2（已实现，待真实服务验收）：文本主模型按需调用独立图片理解应用能力，复用统一 Tool Interface；自动携带原始问题、必要上下文，支持关注点、同轮复用和重新看原图；显式区分原图与识图摘要，不宣称两者等效。见 [M2规格](M2-application-vision.md)。
4. M3（未实施）：AgentScope/DSH 原生多模态传输、跨员工图片授权、缩放/像素预算、附件配额/未发送附件回收、图片质量 Benchmark。

回滚：关闭模型视觉开关，使用纯文本新会话；保留旧会话和本地原图。部署须按 contracts → agent-core → orchestrator → API 构建顺序重新启动 API，避免旧 dist 吞掉新增附件字段。
