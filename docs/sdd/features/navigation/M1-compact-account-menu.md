# NAV-M1 · 紧凑账户与配置入口

状态：已实现，自动化工程验证通过，待桌面安装态视觉验收。

## 需求

- NAV-R1：登录用户的账户信息、外观、设置与退出操作默认收敛到侧栏底部单行入口，不持续占用最近对话区域。
- NAV-R2：入口保留头像、用户名称和服务状态；完整账号与组织信息按需显示。
- NAV-R3：点击入口打开浮层；点击外部、按 Escape、选择设置或退出后关闭。
- NAV-R4：侧栏折叠时复用同一头像入口，浮层向右展开；侧栏展开按钮始终可用。
- NAV-R5：使用 `aria-haspopup`、`aria-expanded`、`menu` 和 `menuitem` 暴露可访问状态。

## 设计与验收

浮层位于账户入口上方，保持外观、设置、退出三项的主次关系；服务状态以头像角标和次级文字呈现。最近对话继续使用独立滚动区域。

- NAV-T1：`scripts/sidebar-account-menu-regression.mjs` 验证紧凑入口、菜单语义、Escape/外部关闭和折叠态展开入口。
- NAV-T2：Renderer 类型检查与生产构建通过。

## 回滚与兼容

仅改变 Renderer 展示与交互，不涉及数据、契约或迁移；可直接恢复原账户卡片回滚。
