# Windows 用户手册加载性能

> 状态：已接受｜规格版本：1.0｜更新日期：2026-09-29

| ID | 需求 | 验收摘要 |
| --- | --- | --- |
| MANUAL-PERF-01 | 用户进入手册后必须立即看到明确的加载状态，不能长时间白屏。 | 手册代码和内容尚未就绪时显示加载组件或正文骨架。 |
| MANUAL-PERF-02 | 手册不得增加应用初始主包的同步加载负担。 | `DocsPage` 作为独立异步 chunk，仅在进入手册时加载。 |
| MANUAL-PERF-03 | 长手册不得一次性创建全部正文 DOM。 | 按二级标题分章，每次只挂载当前章节。 |
| MANUAL-PERF-04 | 目录和外部锚点仍可准确打开对应章节。 | 点击二、三级目录或从模型引导进入时，先切章再定位。 |
| MANUAL-PERF-05 | 手册图片不得引起不必要的传输、同步解码和大幅布局跳动。 | 应用内使用 WebP，图片延迟加载、异步解码，并声明固有尺寸和宽高比；PNG 仅作为文档原图保留。 |
| MANUAL-PERF-06 | Markdown 转换不得占用客户端运行时主线程。 | 开发、类型检查和构建前生成章节 HTML/JSON；renderer 只读取生成结果。 |

## 边界

- 不改变手册 Markdown 的事实源与内容维护方式。
- 不改变桌面端 API、存储、模型和权限契约。
- 本阶段不引入新的 Markdown 第三方运行时；现有白名单转换器移动到 Node 构建脚本。

## 回滚

恢复 `App.vue` 的静态组件导入，并让 `DocsPage` 使用完整 HTML，即可回到原有全文阅读模式；Markdown 文件和图片无需迁移。
