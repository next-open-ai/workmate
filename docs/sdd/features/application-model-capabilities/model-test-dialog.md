# AMC-TEST-001 · 配置模型测试弹窗

状态：已实现，工程验证通过，待真实 Provider 人工验收。

## 需求

- 每个已配置模型行都提供统一“测试”入口。
- 弹窗展示 Provider、模型 ID、能力类型、测试范围、耗时和结构化结果。
- Embedding 发送真实最小向量请求并校验维度。
- 生图提供可编辑预设提示词，显式点击测试后真实生成 1024×1024 图片并原位预览；TTS 真实合成并可播放；量子代码展示真实输出。
- 对话模型使用预设需求发起真实对话；视觉和 ASR 支持上传不超过 2 MB 的图片/音频样本并展示真实结果。
- 测试结果写回模型健康状态；失败按配置、权限或临时不可用分类。
- 密钥不展示在弹窗或结果中。
- 弹窗高度不得超过当前视口；内容超长时仅中间内容区滚动，标题栏关闭入口与底部操作区始终可见。
- 图片结果按视口自适应预览，不得将弹窗操作区挤出屏幕。
- 测试执行期间展示平滑进度、当前阶段和已耗时；等待真实结果时进度不得提前到达 100%，成功或失败后由结果状态接管。
- 弹窗采用严格模态交互：点击遮罩不得关闭；测试执行期间所有关闭入口禁用，测试结束后只能通过显式关闭按钮退出。
- 视觉测试必须复用正式图片理解链路的流式协议、MaaS 模型 ID 归一化和载荷适配，不得维护独立的简化请求实现；网络错误保留底层错误码和原因。

## 验收

- AMC-TEST-T1：七类模型均显示测试入口和能力说明；弹窗支持首次测试与重新测试。
- AMC-TEST-T2：成功/失败结果包含耗时，模型健康状态同步更新。
- AMC-TEST-T3：Renderer 类型检查与生产构建通过。
- AMC-TEST-T4：生成图片或出现长结果后，弹窗仍限制在视口内，内容区可滚动，关闭与重新测试按钮保持可操作。
- AMC-TEST-T5：开始测试后立即出现可访问的进度条、阶段文案与秒级耗时，长任务缓慢推进且在服务响应前停留于 92% 以下。
- AMC-TEST-T6：点击弹窗外部不退出；运行期间顶部和底部关闭按钮均不可操作，完成或失败后恢复。

测试样本与生成结果仅用于当前弹窗，不写入资产库；关闭弹窗后释放。
