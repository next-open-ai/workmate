# 需求规格

> 状态：待评审｜规格版本：0.1｜更新日期：2026-09-23

| ID | 需求 | 验收摘要 |
| --- | --- | --- |
| ONT-01 | 系统应按知识库保存节点、关系、属性、别名、来源和发布状态。 | 重启后可读取；不同知识库隔离。 |
| ONT-02 | 查询应识别标准名称及别名，并返回匹配实体、相邻关系、扩展词和结构化条件。 | “退钱没收到”可归一到“退款未到账”。 |
| ONT-03 | 原始问题的向量召回必须始终保留，不因图谱缺失或误识别而被阻断。 | 无图谱或无匹配时退化为普通向量检索。 |
| ONT-04 | 图谱结果应增强而非替代向量检索，可扩展查询、提供目标文档提示和排序信号。 | 结果中可观察检索策略与查询计划。 |
| ONT-05 | 权限、有效期、版本和适用范围属于确定性过滤职责，不得交给大模型自由决定。 | 后续过滤层必须位于模型上下文组装之前。 |
| ONT-06 | 图谱结论应能追溯到原始文档、切片、项目、流程或经验。 | 节点/关系支持 source 与 documentId 等证据引用。 |
| ONT-07 | 第一阶段应支持本体替换、读取、查询和混合检索 API。 | 契约校验失败返回 400；成功结果结构稳定。 |

## 非目标

- 不建设完整企业级图数据库；
- 不实现三跳以上复杂推理；
- 不允许模型抽取结果未经审核自动成为正式制度；
- 不在第一阶段替换 LanceDB、云知识库或现有经验存储；
- 暂不承诺本体编辑 UI 和自动文档抽取。
