# 实施计划

> 状态：实施中｜规格版本：0.1｜更新日期：2026-09-23

## P1：最小技术闭环

定义契约，完成按知识库持久化、别名匹配、一跳关系扩展、原始向量保底、本体增强向量召回、融合排序和调试 API。

## P2：证据和治理闭环

补充节点/关系增量维护、文档与切片稳定关联、权限/时效/版本硬过滤、冲突优先级、操作审计和迁移策略。

## P3：产品闭环

增加知识库内的本体维护与检索调试界面；支持候选知识审核；将混合检索受控接入 `kb_search`，并建立离线评测集。

## P4：自动沉淀

从文档、项目、流程和经验中抽取候选实体关系，经本体校验与人工审核后发布；按规模评估是否引入专用图数据库。

## 回滚原则

混合检索必须是可关闭的增强路径。回滚后继续使用现有 `searchKnowledgeBase`，不得破坏已有向量索引和文档数据。
