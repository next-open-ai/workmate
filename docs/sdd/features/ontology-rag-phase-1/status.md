# 当前状态

> 状态：实施中｜规格版本：0.1｜更新日期：2026-10-03

已完成第一阶段技术骨架：公共契约、sql.js/SQLite 图谱存储、确定性别名和一跳查询规划、原始向量保底、本体增强双路召回、结果融合及相关 API。SQLite 按知识库隔离，包含节点、关系、候选、版本快照和元数据表，并兼容首次导入旧 JSON 图谱。

已新增第一个人工治理小闭环：知识库内维护本体草稿、发布版本、导入带证据候选、接受/拒绝审核、提交正式图谱，并可立即由现有查询规划和混合检索命中。候选契约强制包含 documentId、可选 chunkId 与原文引用。

自动抽取小闭环已接通：用户选择知识库文档和可选分析重点，系统读取真实切片并调用当前应用模型识别实体与关系；服务端校验模型证据只能引用本次授权切片，随后写入 pending 候选。用户可以逐条或批量审核，只有接受并明确提交后才进入正式图谱。默认界面采用业务流程，高级 JSON 编辑折叠保留。

多切片识别已改为有界分批执行：默认每批最多 4 个切片且正文不超过约 10000 字符，顶层批次最多并发 2 个，并按原批次顺序合并结果。每批输出预算为 8000 token，提示模型最多返回 20 个节点和 30 条关系，并逐个检查输入切片。模型返回截断或非法 JSON 时，服务端先将失败批次二分重试；若单个密集切片仍失败，再仅在模型分析上下文中按自然边界缩小文本窗口。知识库中已保存的原切片及其 ID 不发生变化，证据仍绑定原切片。全部批次成功后才统一写入审核队列，避免半成品候选。

正式本体关系图支持沉浸式全屏查看。全屏状态保留搜索定位、布局切换、缩放和节点/关系详情，并在进入、退出或窗口尺寸变化时刷新 Cytoscape 画布；用户可通过标题区按钮或 Esc 退出。

本体查询已扩展为受控的两跳图查询：可约束实体类型、关系谓词、属性、方向和结果数量，查询计划返回可解释路径、命中谓词和实体/关系证据引用。混合检索在原始向量与本体扩展向量之外，增加正式图谱绑定切片的定向召回；验证界面显示逻辑路径、证据数量和每条结果的召回来源。当前不开放任意 SPARQL 或 SQL 执行，外部 RDF/OWL 互操作仍属于后续阶段。

证据治理采用候选级隔离：模型改写、概括或编造而无法在原文核验的引用会连同该候选被丢弃，依赖无效节点的关系也不会进入审核区；同批其他证据可信的候选继续处理。引用本次未授权 chunkId 仍视为安全边界错误并拒绝请求。

Agent 默认检索已经接入：`kb_search` 默认执行本体查询规划、图谱证据召回与向量融合，每个知识库可独立关闭；本体异常时自动退回原始向量检索。发布与回滚仅允许管理员执行，发布人由登录身份自动记录。尚未完成的是细粒度知识权限/时效硬过滤、稳定文档版本绑定和真实业务评测，因此仍不能宣称完整第一阶段已经产品化。

下一验收门槛：完成 ONT-T06～T08，并用一组包含同义词、错误图谱、无图谱、过期知识和越权知识的真实问题集验证。
