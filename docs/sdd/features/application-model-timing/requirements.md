# 应用模型执行耗时显示

> 状态：已实现｜规格版本：1.1｜更新日期：2026-09-29

| ID | 需求 | 验收摘要 |
| --- | --- | --- |
| APPMODEL-TIME-01 | 应用模型执行中应持续显示已耗时长。 | `model:*` 活动每 250ms 刷新计时。 |
| APPMODEL-TIME-02 | 应用模型完成或失败后应保留最终耗时。 | 活动持久化 `startedAt` 和 `durationMs`，历史记录可回显。 |
| APPMODEL-TIME-03 | 计时不得改变模型调用、进度和结果语义。 | 仅扩展活动元数据和展示。 |
| APPMODEL-TIME-04 | 图片理解等长时应用模型调用应展示可理解的真实阶段。 | 图片理解依次显示会话临时区读取、模型提交、远程等待、结果校验和交回主模型；10/30/60 秒等待节点原位更新。 |
| APPMODEL-TIME-05 | 图片理解完成后应保留关键阶段耗时，便于判断本地处理或远程服务瓶颈。 | 完成摘要及工具结果包含读取、远程模型和总耗时；不把远程请求总耗时伪装成纯网络或纯推理耗时。 |
