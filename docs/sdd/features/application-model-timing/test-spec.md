# 测试规格

| 场景 | 预期 |
| --- | --- |
| 应用模型开始 | 活动包含 `startedAt`，界面开始实时计时 |
| 应用模型成功 | 活动包含非负 `durationMs`，界面固定最终耗时 |
| 应用模型失败或中止 | 同样保存终止时的耗时 |
| 历史记录 | 重新加载活动后仍显示持久化耗时 |
| 图片理解快速完成 | 状态至少经过临时读取、模型提交、结果校验和完成，结果含分段耗时 |
| 图片理解长时等待 | 10、30、60 秒节点原位更新远程模型等待时长，不产生额外执行步骤 |
| 耗时归因 | 完成摘要区分本地读取、远程视觉请求和总耗时，不声称可区分网络、服务排队与模型推理 |
